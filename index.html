X3 日漫转换器（图片 / PDF / ZIP / EPUB / CBZ）

选择日漫总文件夹，自动裁切白边、识别彩页和双页扫描；单页可保持整页或切成 2/3 个带重叠的横向阅读视窗。保留章节识别、批量合并、XTC/XTCH、预览、图像调节和自动保存等功能。所有处理均在本机浏览器完成，不会上传图片。

① 选择漫画

请选择包含各章节子文件夹的漫画总文件夹，目录结构应为“漫画名/章节文件夹/图片”。选择后请确认识别到的章节数量；如果显示“未分章图片”或章节数为 0，说明浏览器没有提供完整目录路径，无法自动分章，请换 Chrome 再试。

② 输出方式

所有图片合并为一个 XTC/XTCH 文件。

③ 日漫分割设置与转换

彩页自动整页保留。铺满屏幕会将页面填满 X3；保持原图比例会等比缩放并在空余处留白。保持原图比例时可调整分割重叠像素；铺满屏幕时使用内部切线调整参数。宽幅扫描默认尝试检测白色中缝，识别成功时按日漫顺序先输出右页、再输出左页；勾选“整本双页扫描”则即使没有明显白缝也会按中线分开。封面始终不切分；也可设置前 N 张图片不切分。

0

负值变暗，正值变亮；默认 0。

100%

控制误差扩散的强弱；0% 不扩散误差，100% 使用完整算法强度。Ordered 和无抖动模式不使用误差扩散。

128

仅在黑白（XTC）模式下生效。数值较低时更容易变白，较高时更容易变黑。
